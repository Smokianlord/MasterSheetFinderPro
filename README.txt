Master Sheet Finder Pro v6
==========================

What changed in this version:
- More professional colorful UI
- Dashboard cards for total rows, showing rows, tradelinks, skin sites, banned rows
- Cleaner table view by default
- Right-side account panel with copy buttons beside useful fields
- Skin-site section with Copy buttons for IDs/links
- Search in SkinClub/KeyDrop/etc. automatically changes the quick-copy button
- Filtered CSV export button
- Still keeps passwords/tokens hidden by default

Run without EXE:
1. Install Python 3.11 or newer.
2. Double-click RUN_APP.bat.
3. Open your exported Google Sheet CSV/XLSX.

Build Windows EXE:
1. On your Windows PC, unzip this folder.
2. Double-click BUILD_EXE.bat.
3. Wait for the build to finish.
4. Your EXE will be here:
   dist\MasterSheetFinderPro.exe

Notes:
- Your actual sheet data is NOT included in this zip.
- XLSX support needs openpyxl. BUILD_EXE.bat installs it automatically.
- CSV works fastest and is recommended.
