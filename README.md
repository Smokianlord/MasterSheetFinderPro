# MasterSheetFinder Pro

A desktop app for searching and filtering large giveaway/account sheets easily.

## Features

- Search by Profile Name, Steam Name, Steam Username, Email, SteamID64, and Tradelink
- Filter by tradelink, email, banned/active status
- Skin-site filters for DMarket, KeyDrop, ForceDrop, CSGOFast, Hellcase, CSGO.Net, SkinClub, Juice.gg, Casehug, and DaddySkins
- Copy buttons for username, password, email, tradelink, and site IDs/links
- Export filtered results as CSV
- Professional colorful desktop UI

## Privacy

This app does not include any sheet data.
Do not upload your personal CSV/XLSX files to GitHub.
